# LAC-HD 数据附件

标注原则以论文附录 A 为准，完整英文版见 ANNOTATION_PROTOCOL.md。knowledge 是主要事实依据，dialogue history 用于语境和指代；参考响应只能辅助，不能覆盖 knowledge；不使用外部世界知识。最小连续的错误、捏造、无支持或矛盾事实跨度标为 1，其余为 0。关系错误标记承载关系内容的 token，功能词和标点通常为 0，模糊措辞不豁免无依据事实。token 序列保持不变。

GPT-5.6-Sol 对全部 10,000 条幻觉候选预标注，两名审核者独立检查 token 标签与跨度、修正漏标误标及边界错误，并讨论分歧。划分前剔除 171 条标注仍未解决或质量不足的候选，保留 9,829 条。两名审核者也检查全部 10,000 条参考响应，确认全零 token 标签。参考响应作为独立检测样本，不加入对应候选的检测输入。

固定 90/5/5 分组划分后，各模型共用同一批 991 条测试响应及由有效 scored token 聚合的回答级标签：原始 491 正例、500 负例，28 个正例转负、没有负例转正，最终 463 正例、528 负例。共享标签与这 28 个 ID 位于 evaluation/。全数据集的 536 个全零原始正例不等于测试集转换数量。

本目录含标注、划分、171 个剔除 ID、跨任务索引、元数据和重建脚本，不含原始文本或权重。

```bash
python scripts/reconstruct_data.py --source /path/to/HaluEval/data/dialogue_data.json --output_dir ../LAC-HD_code/data
```

重建后 loader 使用的字段已逐条与现有项目比对通过；每个骨干的有效 token 对齐还需在实际评估时与共享标签校验。
